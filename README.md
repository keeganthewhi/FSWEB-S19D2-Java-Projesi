## About

Introduces Spring Security fundamentals for securing web applications. This assignment covers authentication, authorization, password encoding, and configuring security filters for REST APIs.

## Key Concepts

- Spring Security configuration and filter chain
- Authentication with `UserDetailsService`
- Password encoding with `BCryptPasswordEncoder`
- Role-based authorization and endpoint protection
